# Task 4 – End-to-End Sales Analytics Capstone

## Objective
Perform complete data science workflow on retail sales dataset.

## Workflow
- Data Cleaning & Preprocessing
- KPI Computation
- Time Series Analysis
- Product & Category Performance
- Regional & Segment Analysis
- Discount Impact Study

## Key Insights
- Revenue concentrated in top products and regions.
- Seasonal trends identified.
- High discounts negatively impact profit margins.
- Certain customer segments drive majority revenue.

## Tools Used
Python, Pandas, Matplotlib, Seaborn
